# portfolio

A scalable Flutter portfolio platform built using Clean Architecture, Riverpod state management, and Firebase backend services. The project targets Web, Android, and iOS and features dynamic content management via Firestore, responsive UI design, multilingual support, theme persistence with Hive, advanced scroll animations, and modular feature-based architecture.
